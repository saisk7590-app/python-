## 📌 Overview

The **Personal Productivity Hub** is a terminal-based Python application that helps manage daily productivity tasks in one unified system.

It combines:

- Task Manager
- Notes Manager
- Expense Tracker
- Student Records System

All data is stored locally using file handling.

---

## 🎯 Features

### ✅ Task Manager
- Add tasks
- View tasks
- Complete tasks
- Delete tasks
- Persistent storage

---

### 📝 Notes Manager
- Add notes
- View notes
- Delete notes

---

### 💰 Expense Tracker
- Add expenses
- View all expenses
- Calculate total spending
- Delete expenses

---

### 🎓 Student Records
- Add students
- View students
- Search students
- Delete students
- Pass/Fail status system

---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- File Handling (read/write operations)
- Exception Handling
- Modular Programming
- CLI (Command Line Interface) design
- Data Serialization (object ↔ text conversion)
